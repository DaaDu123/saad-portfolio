# Muhammad Saad - Portfolio (React + Vite)

## Run
    npm install
    npm run dev        # http://localhost:5173
    npm run build      # production build in /dist (deploy to Vercel/Netlify)

## Edit your data
All content (bio, skills, experience, projects, services) lives in `src/data.js`.
To add links, put them in `src/data.js` and use them in the components.
